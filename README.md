# hsvdepaardenvriend.nl

WordPress-thema voor HSV De Paardenvriend (Reuver).

- `paardenvriend/` – het thema (Bootstrap 5, Lora + PT Sans lokaal, sponsoren). Zie `paardenvriend/README.md`.

De agenda, startlijsten en uitslagen komen uit de aparte plugin **HSV Wedstrijden** (`hsv-wedstrijden`), die eerst geïnstalleerd moet zijn.
